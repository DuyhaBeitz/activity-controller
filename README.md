# MIET project for java
## ТЗ
### Задача № 1.2. Контроллер активности.
https://disk.yandex.ru/d/7UOTgtl-nqYgZA

Предложить решение для задачи контроля и предсказания работоспособности сетевого сервиса, например сайта. Программа должна собирать
информацию об активности сетевого сервиса (время ответа, время окончания передачи данных и т.д.) и присылать (например, на почту) сообщение об
ошибке, в случае не работоспособности сервиса с учетом характера ошибки: нет доступа (не пингуется), не может быть найден, долгое время ответа,
ответ с ошибкой и т.д. Предусмотреть два варианта программы:
1 Программа не имеет доступа к компьютеру сервиса.
2 Программа имеет доступ к компьютеру сервиса.
Во втором случае программа должна легко (за час) ставится администратором машины (любая на выбор - Unix-ориентированные ОС) и собирать
характеристики компьютера: количество занятой памяти, загрузку процессора и т.д. с тем чтобы совмещая эти показатели с показателями при падении
сервиса получать диапазоны значений, «говорящих» о приближении ситуации с потенциальной проблемой.
Программа должна быть обеспечена визуализацией на карте (YandexMap или GoogleMap или OpenStreetMap или «собственного производства»)
показывающей местоположение проблемных «территорий» (закрашенные соответствующим цветом области) по заранее заданному критерию
«проблемности» в виде % времени непрерывной работы, а также послойную визуализацию по ошибкам (каждому типу ошибки — свой слой) с учетом
временной динамики изменения.
